# 릴리스 체크리스트

버전: ____  ·  날짜: ____

## 빌드 전
- [ ] `versionCode`를 올렸다 (같은 번호는 업로드가 거부된다)
- [ ] `versionName`을 갱신했다
- [ ] targetSdk가 현재 Play 요건을 만족한다
- [ ] 비밀번호·토큰이 코드나 기본값에 남아 있지 않다

## 빌드 후
- [ ] 실기기에서 설치·실행했다
- [ ] 신규 설치와 **덮어쓰기 설치**를 모두 확인했다
- [ ] 오프라인 상태에서 앱이 죽지 않는다
- [ ] 서명을 검증했다 (`apksigner verify --print-certs`)
- [ ] 웹 자산을 고쳤다면 캐시 버전을 올렸다

## 업로드
- [ ] AAB를 업로드 키로 서명했다
- [ ] 출시 노트를 작성했다
- [ ] 스크린샷이 현재 화면과 일치한다 (옛 버그가 담겨 있지 않은지)

## 배포 후
- [ ] 실제 다운로드 링크로 받아 설치했다
- [ ] 키스토어 백업이 최신인지 확인했다
- [ ] 오답노트에 새로 겪은 것을 적었다
