# 0001. 앱을 WebView 셸로 만든다

*2026-08-08 · 상태: 채택 (상업화 시 재검토 필요)*

## 맥락
히트맵 화면이 이미 GitHub Pages에 D3로 구현되어 있었다. 안드로이드 앱이 필요했다.

## 결정
네이티브로 다시 그리지 않고, WebView로 Pages를 띄우는 얇은 셸을 만든다.
앱이 직접 담당하는 것은 오프라인 재시도 UI, 뒤로가기 히스토리 연결,
복귀 시 새로고침 세 가지뿐이다.

## 이유
- 시각화를 고칠 때마다 APK를 재빌드·재설치하지 않아도 된다. 푸시하면 반영된다.
- 앱 크기 21KB, 빌드 수 초.
- 개인·지인 배포가 목적이라 스토어 정책 제약이 없다.

## 대가
- **Play 스토어 정식 등록에는 부적합하다.** 웹사이트의 웹뷰 제공이 주 목적인 앱은
  최소기능 정책에 걸린다.
- 수익화를 하려면 화면을 앱에 내장하고 네이티브 기능을 추가해야 한다.

## 재검토 조건
스토어 프로덕션 출시 또는 수익화를 결정하는 시점.
