# 00. 로드맵 — 처음부터 수익화까지

*최종 확인: 2026-08-08*

```
[0] 만들 것 정하기
     ↓
[1] 개발자 계정 ──── 신원 인증에 수일. 가장 먼저 시작할 것
     ↓
[2] 앱 만들기 ───── 여기가 제일 빠르다. 착각하기 쉬운 부분
     ↓
[3] 사이드로드 배포 ─ APK 링크 공유. 여기까지는 하루면 된다
     ↓
[4] Play 내부 테스트 ─ AAB 필요. targetSdk 요건 확인
     ↓
[5] 비공개 테스트 ─── 개인 계정은 테스터 12명 × 14일. 일정의 대부분
     ↓
[6] 프로덕션 출시
     ↓
[7] 수익화 ───────── 데이터·콘텐츠 라이선스가 진짜 관문
```

## 시간 배분의 현실

처음에는 "앱 만들기"에 시간이 다 들 거라 예상하지만 실제로는 반대다.

| 단계 | 실제 소요 | 성격 |
|---|---|---|
| 앱 만들기 | 수 시간~며칠 | 내가 통제 가능 |
| 계정 신원 인증 | 수일 | 대기 |
| 첫 비공개 테스트 릴리스 검토 | 최대 7일 | 대기 |
| 테스터 12명 × 14일 | 최소 14일 | 대기 + 사람 모으기 |
| 프로덕션 액세스 심사 | 수일 | 대기 |

**대기 시간이 압도적이다.** 그래서 순서가 중요하다 — 계정 인증은 앱을 만들기
전에 시작해도 된다. 병렬로 돌릴 수 있는 건 전부 병렬로 돌린다.

## 첫 앱에서 하지 말 것

- **완성도를 올리다 배포를 미루는 것.** 사이드로드 APK까지는 하루면 된다.
  폰에 깔고 써 보면 우선순위가 완전히 바뀐다.
- **처음부터 수익화를 전제로 설계하는 것.** 라이선스 조건이 아키텍처를 바꾼다.
  무료로 만들되, 나중에 교체 가능한 구조인지만 확인해 둔다.
- **개인 계정으로 프로덕션 일정을 약속하는 것.** 14일 테스트가 강제된다.
  사업자가 있다면 조직 계정이 이 요건에서 자유롭다.
